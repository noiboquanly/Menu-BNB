BẾP NHÀ BÀ — BẢN KHÔNG CẦN VISUAL STUDIO / C++

CÁCH NHANH NHẤT:
1. Giải nén ZIP.
2. Nhấp đúp CHAY-WEBSITE.bat.
3. Lần đầu chương trình tự npm install.
4. Trình duyệt tự mở http://localhost:3005

Hoặc CMD:
npm install
npm start

Dữ liệu:
- data/menu.json: menu
- data/reservations.json: các yêu cầu đặt bàn

Bản này không dùng better-sqlite3/node-gyp nên không cần Visual Studio Build Tools.
